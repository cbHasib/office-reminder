# Office Reminder Mobile

Standalone Expo mobile app for Office Reminder.

## Setup

```bash
cd apps/mobile
pnpm install
pnpm start
```

## Useful Commands

```bash
pnpm ios
pnpm android
pnpm ts:check
pnpm doctor
```

This folder is intentionally self-contained. It has its own `package.json`, `pnpm-lock.yaml`, `pnpm-workspace.yaml`, and local copy of shared mobile types/helpers under `src/lib/shared`.
